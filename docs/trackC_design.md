## 1. QAOA for Max-Cut

### 1.1 Problem Formulation & Cost Hamiltonian
Given an undirected graph $G = (V, E)$ with edge weights $w_{uv} > 0$ on $n = |V|$ vertices, Max-Cut partitions $V$ into two disjoint subsets to maximize the weight of cut edges:
$$\text{Cut}(x) = \sum_{(u, v) \in E} w_{uv} (x_u \oplus x_v) = \sum_{(u, v) \in E} w_{uv} \frac{1 - z_u z_v}{2}$$
where binary variables $x_u \in \{0, 1\}$ map to Ising spin values $z_u \in \{-1, +1\}$ via $z_u = 1 - 2x_u$.

Promoting spins to Pauli $Z$ operators gives the problem (cost) Hamiltonian:
$$H_C = \sum_{(u, v) \in E} w_{uv} \frac{I - Z_u Z_v}{2}$$
$H_C$ is diagonal in the computational basis $\{|x\rangle : x \in \{0, 1\}^n\}$, with eigenvalues equal to the classical cut value:
$$H_C |x\rangle = \text{Cut}(x) |x\rangle$$

### 1.2 Transverse-Field Mixer & QAOA Circuit
The transverse-field mixer Hamiltonian is:
$$H_M = \sum_{j=0}^{n-1} X_j$$
Starting from the uniform superposition $|+\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}} \sum_{x \in \{0, 1\}^n} |x\rangle$, a $p$-layer Quantum Approximate Optimization Algorithm (QAOA) prepares the parameterized state:
$$|\psi(\boldsymbol{\gamma}, \boldsymbol{\beta})\rangle = \prod_{l=1}^p \left( e^{-i \beta_l H_M} e^{-i \gamma_l H_C} \right) |+\rangle^{\otimes n}$$
where:
- The phase separation operator $e^{-i \gamma_l H_C} = \prod_{(u, v) \in E} e^{-i \gamma_l w_{uv} \frac{I - Z_u Z_v}{2}}$ imparts phase shifts proportional to edge cuts.
- The mixer operator $e^{-i \beta_l H_M} = \bigotimes_{j=0}^{n-1} e^{-i \beta_l X_j} = \bigotimes_{j=0}^{n-1} R_{X_j}(2\beta_l)$ drives quantum tunneling between configurations.

### 1.3 Objective Function
The optimization objective is the expected cut value:
$$\langle C \rangle(\boldsymbol{\gamma}, \boldsymbol{\beta}) = \langle \psi(\boldsymbol{\gamma}, \boldsymbol{\beta}) | H_C | \psi(\boldsymbol{\gamma}, \boldsymbol{\beta}) \rangle = \sum_{x \in \{0, 1\}^n} \text{Cut}(x) \, |\langle x | \psi(\boldsymbol{\gamma}, \boldsymbol{\beta}) \rangle|^2$$
We seek parameters $(\boldsymbol{\gamma}^*, \boldsymbol{\beta}^*) = \arg\max \langle C \rangle$.

## 2. Gradient Computation: Parameter-Shift Rule vs Naive Shift

### 2.1 The Two-Eigenvalue Condition
The standard parameter-shift rule allows exact analytical gradient calculation on quantum circuits without numerical step sizes. However, it is mathematically exact **only** for gates generated by operators with two distinct eigenvalues $\lambda_1, \lambda_2$:
$$\frac{d}{d\theta} \langle \psi | U^\dagger(\theta) O U(\theta) | \psi \rangle = r \cdot \frac{f(\theta + s) - f(\theta - s)}{2 \sin(r \cdot s)}$$
For generators with eigenvalues difference $r = 1$ (such as Pauli rotations $e^{-i \frac{\theta}{2} P}$ or projectors $e^{-i \theta \Pi}$ with eigenvalues $\{0, 1\}$), choosing shift $s = \frac{\pi}{2}$ gives:
$$\frac{\partial f}{\partial \theta} = \frac{f(\theta + \frac{\pi}{2}) - f(\theta - \frac{\pi}{2})}{2}$$

### 2.2 Why Naive Parameter Shift Fails on Multi-Gate Hamiltonians
In QAOA on a weighted graph, the total cost unitary is $e^{-i \gamma H_C}$. The full Hamiltonian $H_C = \sum_{e} w_e \Pi_e$ has a rich discrete spectrum of eigenvalues $\{C(x)\}_{x \in \{0, 1\}^n}$, spanning many frequencies. Shifting the shared parameter $\gamma$ by $\pm \frac{\pi}{2}$ evaluates $\frac{f(\gamma + \pi/2) - f(\gamma - \pi/2)}{2}$, which breaks down completely and yields order-of-magnitude errors because $H_C$ does not satisfy the two-eigenvalue condition.

### 2.3 The Exact Per-Gate Parameter-Shift Rule
To compute exact analytical gradients for $\gamma_l$, the shift rule must be applied **per gate occurrence** and combined via the multivariate chain rule:
- Each individual edge gate $U_e(\theta_e) = e^{-i \theta_e \frac{I - Z_u Z_v}{2}}$ has generator $\Pi_e = \frac{I - Z_u Z_v}{2}$ whose eigenvalues are strictly $\{0, 1\}$ (two eigenvalues, difference $r = 1$).
- Shifting each edge angle $\theta_e = \gamma_l w_e$ individually by $s = \frac{\pi}{2}$:
  $$\frac{\partial \langle C \rangle}{\partial \theta_e} = \frac{\langle C \rangle_{\theta_e + \pi/2} - \langle C \rangle_{\theta_e - \pi/2}}{2}$$
- Applying the chain rule over all $|E|$ edge gates:
  $$\frac{\partial \langle C \rangle}{\partial \gamma_l} = \sum_{e \in E} \frac{\partial \langle C \rangle}{\partial \theta_e} \frac{\partial \theta_e}{\partial \gamma_l} = \sum_{e \in E} w_e \left[ \frac{\langle C \rangle_{\theta_e + \pi/2} - \langle C \rangle_{\theta_e - \pi/2}}{2} \right]$$
- Similarly for mixer angle $\beta_l$: each single-qubit mixer gate is $R_{X_j}(2\beta_l) = e^{-i \beta_l X_j}$. Shifting each rotation angle $\phi_j = 2\beta_l$ by $\pm \frac{\pi}{2}$ (equivalent to shifting $\beta_l$ on qubit $j$ by $\pm \frac{\pi}{4}$):
  $$\frac{\partial \langle C \rangle}{\partial \beta_l} = \sum_{j=0}^{n-1} \left[ \langle C \rangle_{\beta_{l, j} + \pi/4} - \langle C \rangle_{\beta_{l, j} - \pi/4} \right]$$

## 3. Quantum Classical Optimizers

Three classical optimization strategies are compared:
1. **Adam with Parameter-Shift Gradients (`adam_ps`):** First-order adaptive moment estimation using the exact parameter-shift gradient. Each gradient evaluation is accounted as costing $2 \times \text{dim}(\boldsymbol{\theta}) = 4p$ circuit evaluations.
2. **COBYLA (Constrained Optimization BY Linear Approximation):** Derivative-free trust-region simplex method that models the objective by linear interpolations. Evaluates 1 circuit per step.
3. **SPSA (Simultaneous Perturbation Stochastic Approximation):** Derivative-free stochastic gradient approximation (Spall 1992). At step $k$, a random Rademacher vector $\boldsymbol{\Delta}_k \in \{-1, +1\}^{2p}$ simultaneously perturbs all parameters:
   $$\hat{\boldsymbol{g}}_k = \frac{f(\boldsymbol{\theta}_k + c_k \boldsymbol{\Delta}_k) - f(\boldsymbol{\theta}_k - c_k \boldsymbol{\Delta}_k)}{2 c_k} \boldsymbol{\Delta}_k$$
   SPSA requires strictly **two** function evaluations per iteration, regardless of parameter count $2p$, making it especially attractive for noisy, high-dimensional quantum landscapes.

## 4. Finite-Shot Estimation & Shot Noise

In real or simulated shot-based execution, expectation values are estimated by drawing $S$ measurement samples from the final quantum state probability distribution $P(x) = |\psi(x)|^2$:
$$\hat{C}_S = \frac{1}{S} \sum_{s=1}^S \text{Cut}(x^{(s)})$$
By the Central Limit Theorem:
- The estimator is unbiased: $\mathbb{E}[\hat{C}_S] = \langle C \rangle$.
- The estimator variance scales inversely with shot count:
  $$\text{Var}(\hat{C}_S) = \frac{\sigma_0^2}{S} \implies \text{Std}(\hat{C}_S) = \frac{\sigma_0}{\sqrt{S}}$$
  On a log-log plot, $\log \text{Std}(\hat{C}_S)$ vs $\log S$ follows a linear relationship with slope $-0.5$.

## 5. Noise Modeling: Depolarizing Channel

To analyze algorithmic robustness on Noisy Intermediate-Scale Quantum (NISQ) systems, simulated open-system density matrix evolution is performed using PennyLane's `default.mixed` device.
A single-qubit depolarizing channel of probability $q$ is applied to every wire after each cost layer and after each mixer layer:
$$\mathcal{E}_q(\rho) = (1 - q)\rho + \frac{q}{3} \left( X\rho X + Y\rho Y + Z\rho Z \right)$$
As circuit depth $p$ and noise rate $q$ increase, depolarizing channels contract the Bloch sphere, steadily driving $\rho$ towards the maximally mixed state $\frac{I}{2^n}$, which degrades the output distribution toward random assignment ($\langle C \rangle \to \frac{1}{2} \sum w_e$).

## 6. Fair-Comparison Protocol

To ensure rigorous benchmarking across classical and quantum solvers:
- **Identical Instances:** All benchmarks execute on the identical 15 Erdos-Renyi Max-Cut graphs ($n \in \{10, 12, 14\}$, 5 seeds each) generated in Track B.
- **Equal Evaluation Budgets:** Every quantum optimizer (Adam, COBYLA, SPSA) is constrained to an identical budget of **300 circuit evaluations** per run.
- **Multiple Fixed Starts:** Each depth $p \in \{1, 2, 3\}$ is evaluated across 5 reproducible random starts with initial angles $\gamma \in [0, \pi]$, $\beta \in [0, \pi/2]$.
- **Classical Reference Baselines:** Performance is compared against classical Greedy Local Search (20 restarts), Simulated Annealing (10 runs), the theoretical Random Assignment expectation ($\frac{1}{2} \sum w_e$), and the exact global optimum computed via branch-and-bound / ILP.

## 7. Variational Quantum Eigensolver (VQE) & Quantum Natural Gradient (QNG)

> **Notice:** All VQE, QNG, QNN, and barren plateau studies in Part 2 are strictly **SIMULATED** on classical computers using PennyLane `default.qubit` and autograd. No physical quantum processor is used.

### 7.1 VQE & The Variational Principle
For a physical quantum system governed by Hamiltonian $H = \sum_k c_k P_k$ where $P_k \in \{I, X, Y, Z\}^{\otimes n}$ are Pauli strings and $c_k \in \mathbb{R}$, VQE prepares a parameterized ansatz $|\psi(\boldsymbol{\theta})\rangle = U(\boldsymbol{\theta}) |0\rangle^{\otimes n}$.
By the Rayleigh-Ritz variational principle:
$$E(\boldsymbol{\theta}) = \langle \psi(\boldsymbol{\theta}) | H | \psi(\boldsymbol{\theta})\rangle = \frac{\langle \psi(\boldsymbol{\theta}) | H | \psi(\boldsymbol{\theta})\rangle}{\langle \psi(\boldsymbol{\theta}) | \psi(\boldsymbol{\theta})\rangle} \ge E_0$$
where $E_0$ is the exact ground-state eigenvalue. Equality holds if and only if $|\psi(\boldsymbol{\theta})\rangle$ spans the ground eigenspace.

### 7.2 Quantum Natural Gradient (QNG)
Standard Euclidean gradient descent treats parameter space $\mathbb{R}^d$ as flat, but the space of quantum states is Riemannian, equipped with the Fubini-Study metric tensor:
$$g_{ij}(\boldsymbol{\theta}) = \text{Re}\left( \langle \partial_i \psi(\boldsymbol{\theta}) | \partial_j \psi(\boldsymbol{\theta}) \rangle - \langle \partial_i \psi(\boldsymbol{\theta}) | \psi(\boldsymbol{\theta}) \rangle \langle \psi(\boldsymbol{\theta}) | \partial_j \psi(\boldsymbol{\theta}) \rangle \right)$$
The Quantum Natural Gradient step follows the steepest descent along the quantum state manifold:
$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \, (g(\boldsymbol{\theta}_t) + \lambda I)^{-1} \nabla E(\boldsymbol{\theta}_t)$$
where $\lambda > 0$ provides Tikhonov regularization ensuring numerical invertibility of singular or near-singular metrics.
- **Block-Diagonal Approximation:** Restricts $g$ to diagonal parameter blocks corresponding to independent layers or single-qubit gates, computing generator variances under previous-layer states.
- **Circuit Evaluation Cost:** Measuring the metric tensor on quantum hardware or simulators requires extra circuit evaluations (or state-overlap measurements) beyond the $2d$ evaluations of parameter-shift gradient.

## 8. Parameterized Quantum Circuit (PQC) / QNN with Data Re-Uploading

For classification, classical data $\boldsymbol{x} \in \mathbb{R}^m$ is mapped into quantum states using data re-uploading (Pérez-Salinas et al., 2020). By interleaving data encoding rotations $R(\boldsymbol{x})$ and trainable variational rotations $R(\boldsymbol{\theta})$ across multiple layers:
$$U(\boldsymbol{x}, \boldsymbol{\theta}) = \prod_{l=1}^L \left( U_{\text{train}}(\boldsymbol{\theta}_l) \, U_{\text{CNOT}} \, U_{\text{encode}}(\boldsymbol{x}) \right)$$
the circuit acts as a universal quantum function approximator where frequency spectra expand with depth $L$, outputting class prediction $\hat{y}(\boldsymbol{x}) = \langle Z_0 \rangle \in [-1, 1]$.

## 9. Barren Plateaus & Cost Function Locality

In deep, randomly initialized parameterized quantum circuits (McClean et al., 2018), gradient components concentrate sharply around zero:
$$\mathbb{E}_{\boldsymbol{\theta}}[\partial_i E] = 0, \qquad \text{Var}_{\boldsymbol{\theta}}(\partial_i E) \in \mathcal{O}\left(\frac{1}{2^n}\right)$$
- **Global Cost Functions:** For global observables such as projectors onto pure states $C_{\text{global}} = I - |0\dots 0\rangle \langle 0\dots 0|$, the variance decays exponentially in the number of qubits $n$ for depth $\Omega(n)$ (forming approximate 2-designs), creating untrainable barren plateaus.
- **Local Cost Functions:** For local observables measuring individual qubits $C_{\text{local}} = \frac{I - Z_0}{2}$, the variance decays only polynomially at shallow depths $\mathcal{O}(\log n)$, preserving trainability.
